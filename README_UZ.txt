UZBEK LATIN KEYBOARD — Android лойиҳаси

Бу архив Android Studio’да очиладиган манба кодидир; тайёр APK эмас.
A–Z ҳарфлари сақланган. Қўшимча Ö ö, Ğ ğ, Ş ş, Ç ç ҳарфлари алоҳида тугмаларда. ⇧ — катта ҳарф, 123 — рақам ва белгилар.

APK яратиш:
1. Android Studio’да шу архивдан чиқарилган UzbekLatinAndroid папкасини очинг.
2. Gradle sync тугашини кутинг.
3. Build → Build Bundle(s) / APK(s) → Build APK(s) ни танланг.
4. APK одатда app/build/outputs/apk/debug/app-debug.apk манзилида пайдо бўлади.
5. APK’ни телефонга ўтказиб ўрнатинг.
6. Телефон Settings → Keyboard / On-screen keyboard бўлимида Uzbek Latin (Ö Ğ Ş Ç) ни ёқинг ва танланг.

Муҳим:
- Бу манба лойиҳа; бу муҳитда APK сифатида йиғилмаган ва ҳақиқий телефонда синовдан ўтмаган.
- Матнни серверга юбормайди.
- Android версияси ва телефон брендига қараб созламалар номлари фарқ қилиши мумкин.
